# V1 non-goals

V1 does not scrape Marriott, circumvent technical protections, depend on undocumented endpoints, automate booking, require Marriott credentials, connect a Bonvoy account, ingest the global portfolio, promise real-time pricing or award availability, optimize flights, bulk-ingest reviews, build cloud accounts, take payments, or generate unsupported hotel facts with an LLM.

The website must remain useful through a curated catalog and manual pricing. Missing automation is not a reason to create a scraper. Dynamic integration is researched in Stage 12 and requires an approved source and explicit approval at Stage 13. Photos are optional and must be licensed, original, or used through a permitted mechanism.

Stage 0 is narrower: it implements no hotel catalog, benefit rules, rate calculations, recommendation scores, trip data, local profile, certificates, watchlist, maps, or monitoring.
